# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and focus on
what is best for the community. Harassment, personal attacks and
discriminatory language are not tolerated in issues, pull requests,
discussions or any other project space.

## Reporting

Report unacceptable behaviour privately to the maintainers through
[GitHub's report feature](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
or by contacting the repository owner directly. Reports are handled
confidentially. Maintainers may remove comments, commits or other
contributions, and temporarily or permanently ban contributors, as described
in the Contributor Covenant's enforcement guidelines.
